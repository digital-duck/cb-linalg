Linear Equation

Definition. A linear equation in $n$ variables $x_1, x_2, \ldots, x_n$ is an equation of the form

$$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = b,$$

where $a_1, a_2, \ldots, a_n, b \in \mathbb{R}$ are fixed constants called coefficients and the right-hand side, respectively. The defining characteristic is that each variable appears to the first power and no products of variables occur. Equations such as $x^2 + y = 3$ or $xy = 1$ are therefore not linear.

A solution is any $n$-tuple $(s_1, s_2, \ldots, s_n)$ that satisfies the equation when substituted for the variables. The set of all solutions is called the solution set.

Worked Example. Consider the linear equation in two variables

$$3x - 2y = 6.$$

To find solutions, express one variable in terms of the other. Solving for $x$ gives

$$x = \frac{6 + 2y}{3} = 2 + \tfrac{2}{3}y.$$

Setting $y = 0$ yields the point $(2, 0)$; setting $y = 3$ yields $(4, 3)$; setting $y = -3$ yields $(0, -2)$. Each triple confirms the equation. Geometrically, the solution set is the straight line through these points in the $xy$-plane, with slope $\tfrac{3}{2}$ and $x$-intercept $2$.

Key Theorem (Solution Structure). The solution set of a single non-trivial linear equation $a_1 x_1 + \cdots + a_n x_n = b$ (at least one $a_i \neq 0$) is an $(n-1)$-dimensional affine subspace of $\mathbb{R}^n$. Specifically, if $\mathbf{p}$ is any particular solution, then every solution has the form $\mathbf{p} + \mathbf{h}$, where $\mathbf{h}$ satisfies the associated homogeneous equation $a_1 h_1 + \cdots + a_n h_n = 0$.

Proof sketch. If $\mathbf{p}$ and $\mathbf{q}$ are both solutions, then $\mathbf{h} = \mathbf{q} - \mathbf{p}$ satisfies the homogeneous equation by linearity. Conversely, $\mathbf{p} + \mathbf{h}$ is a solution for any homogeneous $\mathbf{h}$. $\square$

Lab Cell (SymPy).

from sympy import symbols, Eq, solve

x, y = symbols('x y')
eq = Eq(3*x - 2*y, 6)

# Solve for x given several values of y
for y_val in [0, 3, -3]:
    sol = solve(eq.subs(y, y_val), x)
    print(f"y = {y_val:>3}  →  x = {sol[0]}")

Running this cell prints the three solutions computed above, confirming that the symbolic solver agrees with hand calculation and reinforcing the idea of a parametric family of solutions along a line.
