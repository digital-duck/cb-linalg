Solving Systems Via Inverse

Definition. Let $A$ be an $n \times n$ matrix and $\mathbf{b} \in \mathbb{R}^n$ a column vector. The linear system $A\mathbf{x} = \mathbf{b}$ has a unique solution for every $\mathbf{b}$ if and only if $A$ is invertible — that is, there exists a unique matrix $A^{-1}$ satisfying $A^{-1}A = AA^{-1} = I_n$, where $I_n$ denotes the $n \times n$ identity matrix. When $A^{-1}$ exists, the solution is obtained by left-multiplying both sides:

$$A\mathbf{x} = \mathbf{b} \implies A^{-1}(A\mathbf{x}) = A^{-1}\mathbf{b} \implies \mathbf{x} = A^{-1}\mathbf{b}.$$

Equivalently, $A$ is invertible if and only if $\det(A) \neq 0$.

Worked Example. Solve the system

$$2x + y = 5, \quad x - 3y = -1.$$

Write this in matrix form $A\mathbf{x} = \mathbf{b}$ with

$$A = \begin{pmatrix} 2 & 1 \\ 1 & -3 \end{pmatrix}, \quad \mathbf{b} = \begin{pmatrix} 5 \\ -1 \end{pmatrix}.$$

Compute $\det(A) = (2)(-3) - (1)(1) = -7 \neq 0$, so $A^{-1}$ exists. For a $2 \times 2$ matrix, the inverse formula gives

$$A^{-1} = \frac{1}{\det(A)}\begin{pmatrix} -3 & -1 \\ -1 & 2 \end{pmatrix} = \frac{1}{-7}\begin{pmatrix} -3 & -1 \\ -1 & 2 \end{pmatrix}.$$

Therefore

$$\mathbf{x} = A^{-1}\mathbf{b} = \frac{1}{-7}\begin{pmatrix} -3(5) + (-1)(-1) \\ -1(5) + 2(-1) \end{pmatrix} = \frac{1}{-7}\begin{pmatrix} -14 \\ -7 \end{pmatrix} = \begin{pmatrix} 2 \\ 1 \end{pmatrix}.$$

One verifies: $2(2) + 1 = 5$ and $2 - 3(1) = -1$. $\checkmark$

Key Theorem (Invertible Matrix Theorem). For an $n \times n$ matrix $A$, the following statements are equivalent: $A$ is invertible; $\det(A) \neq 0$; the columns of $A$ are linearly independent; $A\mathbf{x} = \mathbf{b}$ has a unique solution for every $\mathbf{b}$; and the reduced row echelon form of $A$ is $I_n$. This equivalence underlies the practical utility of the inverse method — whenever any one condition fails, all fail simultaneously and the system either has no solution or infinitely many.

Lab Cell (SymPy).

from sympy import Matrix, symbols

A = Matrix([[2, 1], [1, -3]])
b = Matrix([5, -1])

A_inv = A.inv()          # symbolic inverse
x = A_inv * b            # solution vector
print("A_inv =", A_inv)
print("x =", x)          # Matrix([2, 1])
