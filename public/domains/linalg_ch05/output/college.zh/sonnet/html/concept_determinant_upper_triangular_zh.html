Determinant Upper Triangular

定义。 设 $A = (a_{ij}) \in \mathbb{R}^{n \times n}$ 为上三角矩阵，即当 $i > j$ 时 $a_{ij} = 0$。则 $A$ 的行列式等于其主对角线元素之积：

$$\det(A) = \prod_{i=1}^{n} a_{ii} = a_{11} \cdot a_{22} \cdots a_{nn}.$$

该性质源于行列式的 Leibniz 展开式：$\det(A) = \sum_{\sigma \in S_n} \text{sgn}(\sigma) \prod_{i=1}^{n} a_{i,\sigma(i)}$。对于上三角矩阵，若置换 $\sigma$ 不是恒等置换，则必存在某个 $i$ 使得 $\sigma(i) < i$，从而 $a_{i,\sigma(i)} = 0$，对应项为零。因此求和式中唯一非零项为 $\sigma = \text{id}$，其符号为 $+1$，乘积恰为对角线元素之积。

例题。 计算以下 $3 \times 3$ 上三角矩阵的行列式：

$$A = \begin{pmatrix} 2 & 5 & -1 \\ 0 & 3 & 7 \\ 0 & 0 & 4 \end{pmatrix}.$$

按定义直接读取主对角线：

$$\det(A) = 2 \times 3 \times 4 = 24.$$

无需进行行展开或余子式计算，计算复杂度从 $O(n!)$ 降至 $O(n)$。

关键定理。 设 $A \in \mathbb{R}^{n \times n}$ 为上三角矩阵，则：

  • $A$ 可逆当且仅当所有对角元素均非零，即 $a_{ii} \neq 0$，$\forall i$；
  • $A$ 的特征值恰好为其对角线元素 $a_{11}, a_{22}, \ldots, a_{nn}$（含重数）；
  • 两个上三角矩阵之积仍为上三角矩阵，且积的行列式等于行列式之积：$\det(AB) = \det(A)\det(B)$。

    • 这些性质使得上三角矩阵在 $LU$ 分解与矩阵求解中扮演核心角色：将一般矩阵约化为上三角形式后，行列式的计算量大幅减少。

    实验单元（SymPy）。

    from sympy import Matrix, det, symbols

A = Matrix([[2, 5, -1],
            [0, 3,  7],
            [0, 0,  4]])

print("行列式 =", det(A))                          # 输出：24
print("对角线之积 =", A[0,0] * A[1,1] * A[2,2])   # 输出：24

# 符号矩阵验证一般情形
a, b, c = symbols('a b c')
T = Matrix([[a, 1, 2], [0, b, 3], [0, 0, c]])
print("符号行列式 =", det(T))                      # 输出：a*b*c

    运行上述代码，观察数值与符号两种情形下，行列式始终等于对角元素之积，与非对角元素无关。
