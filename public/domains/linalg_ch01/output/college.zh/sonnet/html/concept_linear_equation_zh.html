Linear Equation

定义。 设 $x_1, x_2, \ldots, x_n$ 为未知量，$a_1, a_2, \ldots, a_n, b$ 为实数常数且不全为零。线性方程（linear equation）是形如

$$ a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = b $$

的等式。其特征在于：每个未知量均以一次幂出现，且未知量之间不存在乘积项。常数 $a_i$ 称为系数（coefficient），$b$ 称为常数项（constant term）。若 $b = 0$，则称方程为齐次的（homogeneous）。

解的几何意义。 在二维情形 $a_1 x + a_2 y = b$ 中，方程的解集构成平面上的一条直线；在三维情形中，解集构成空间中的一张平面。这一几何直觉揭示了"线性"一词的本质来源。

例题。 求解方程 $3x - 2y = 6$，并求其在直线上的两个特殊点。

解： 令 $x = 0$，代入方程得 $-2y = 6$，故 $y = -3$，得点 $(0,\,-3)$。

令 $y = 0$，代入方程得 $3x = 6$，故 $x = 2$，得点 $(2,\,0)$。

通解可表示为参数形式：令 $x = t$（$t \in \mathbb{R}$），则

$$ y = \frac{3t - 6}{2}. $$

该方程的解集为直线 $\ell: 3x - 2y = 6$，其斜率为 $\dfrac{3}{2}$，$y$ 轴截距为 $-3$。

关键定理（线性方程解的结构）。 设 $n$ 元线性方程 $\mathbf{a}^\top \mathbf{x} = b$ 中 $\mathbf{a} \neq \mathbf{0}$。若 $\mathbf{x}_0$ 是其一个特解，则方程的通解为

$$ \mathbf{x} = \mathbf{x}_0 + \mathbf{v}, \quad \mathbf{v} \in \ker(\mathbf{a}^\top), $$

其中 $\ker(\mathbf{a}^\top) = \{\mathbf{v} \in \mathbb{R}^n : \mathbf{a}^\top \mathbf{v} = 0\}$ 是一个 $(n-1)$ 维子空间。直观上，解集是经过特解点、方向由 $\ker(\mathbf{a}^\top)$ 张成的仿射子空间。

实验单元（SymPy）。

from sympy import symbols, Eq, solve, linsolve, Matrix

x, y, t = symbols('x y t')

# 定义方程
eq = Eq(3*x - 2*y, 6)

# 求解（以 y 为自由变量）
sol = solve(eq, x)
print("x =", sol)          # x = 2*y/3 + 2

# 参数化解集
sol_param = solve(eq.subs(x, t), y)
print("参数解:", sol_param) # y = 3*t/2 - 3

# 系数向量与核空间
A = Matrix([[3, -2]])
print("零空间:", A.nullspace())  # [Matrix([2, 3])]
