线性方程

定义

线性方程（linear equation）是仅涉及变量的加法与"变量乘以常数"这两种运算的等式，不包含变量之间的乘积、变量的幂次（如 $x^2$）、也不包含超越函数（如 $\sin x$、$\ln x$）。一般形式为：

$$a_1x_1 + a_2x_2 + \cdots + a_nx_n = b$$

其中 $a_1, a_2, \ldots, a_n$ 与 $b$ 为常数，$x_1, x_2, \ldots, x_n$ 为变量。当只有一个变量时，方程 $ax + b = 0$（$a \neq 0$）的解是唯一的：$x = -b/a$。当存在多个变量时，单个线性方程通常有无穷多组解，这些解的集合在几何上构成一条直线（二维）、一个平面（三维）或更高维空间中的一个"超平面"。

线性方程之所以重要，是因为它是可以用代数方法精确求解的最简单一类方程：不涉及开方、指数增长或三角函数带来的复杂性，求解过程只需要"移项"和"两边同乘（除）一个非零常数"这两条基本操作，且解的存在性与唯一性（在方程个数等于未知数个数、且系数矩阵非奇异时）有完整的理论保证。

实例演算

某工厂日产量的收入模型为：售出 $x$ 件产品，收入 $R = 25x$；固定成本为 $200$ 元，每件产品的可变成本为 $15$ 元，即成本 $C = 200 + 15x$。要求工厂收支平衡的产量 $x$，就是求解方程

$$25x = 200 + 15x$$

移项得 $25x - 15x = 200$，即 $10x = 200$，解得 $x = 20$。也就是说，工厂每天至少卖出 20 件产品才能覆盖成本。

应用与问题求解

线性方程是建立"数量关系模型"的基本工具：只要一个量与另一个量之间保持恒定的变化率（即不随变量本身的大小而改变的比例关系），就可以用线性方程描述。典型应用包括：均匀速度下的路程—时间关系、固定利率下的单利计算、按固定单价定价的成本核算等。求解这类问题的关键步骤是：先明确哪些量是已知常数、哪个量是待求变量，再将题目中的文字关系逐句翻译成等式，最后用移项与两边同除系数的方法分离变量。当模型中出现两个或更多相互关联的线性方程（如上例中的收入与成本），就自然过渡到线性方程组，需要联立求解——这是下一节要讨论的内容。
