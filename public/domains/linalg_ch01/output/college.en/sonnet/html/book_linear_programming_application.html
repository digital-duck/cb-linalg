Payoff

Linear programming is the art of optimizing a linear objective function subject to a finite system of linear inequality constraints. Formally, the standard form of a linear program is:

$$\text{maximize} \quad \mathbf{c}^\top \mathbf{x} \qquad \text{subject to} \quad A\mathbf{x} \leq \mathbf{b},\; \mathbf{x} \geq \mathbf{0},$$

where $\mathbf{x} \in \mathbb{R}^n$ is the decision vector, $\mathbf{c} \in \mathbb{R}^n$ encodes per-unit value, $A \in \mathbb{R}^{m \times n}$ encodes resource consumption, and $\mathbf{b} \in \mathbb{R}^m$ encodes resource limits. The feasible region defined by these constraints is a convex polytope, and the fundamental theorem of linear programming guarantees that an optimal solution, when it exists, is attained at a vertex of this polytope.

This is the natural capstone of the present chapter because every concept introduced earlier — systems of linear equations, matrix representation, feasibility, and convexity — converges here into a single computational framework with immediate, measurable consequences.

Worked example. A small bakery produces loaves ($x_1$) and croissants ($x_2$). Each loaf requires 2 kg of flour and 1 hour of labor; each croissant requires 0.5 kg of flour and 0.75 hours. Available daily: 20 kg flour, 12 hours labor. Profit per unit: \$4 and \$3 respectively. The linear program is:

$$\text{maximize}\quad 4x_1 + 3x_2 \quad \text{s.t.}\quad 2x_1 + 0.5x_2 \leq 20,\quad x_1 + 0.75x_2 \leq 12,\quad x_1,x_2 \geq 0.$$

Enumerating vertices of the feasible polytope yields the optimum at $(x_1, x_2) = (8, 8/3)$, giving a daily profit of approximately \$40.

Theorem (Strong Duality). If a linear program has an optimal primal solution $\mathbf{x}^$, then its dual program also has an optimal solution $\mathbf{y}^$, and $\mathbf{c}^\top \mathbf{x}^ = \mathbf{b}^\top \mathbf{y}^$. The dual variables $\mathbf{y}^$ carry an economic interpretation as shadow prices* — the marginal value of relaxing each constraint by one unit.

from scipy.optimize import linprog
c  = [-4, -3]                          # negate for maximization
A  = [[ 2, 0.5], [1, 0.75]]
b  = [20, 12]
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0,None),(0,None)], method='highs')
print(f"Optimal profit: ${-res.fun:.2f}, plan: {res.x}")
