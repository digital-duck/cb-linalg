Linear Programming Application

Definition. A linear program (LP) is an optimization problem of the form

$$\text{maximize} \quad \mathbf{c}^\top \mathbf{x} \quad \text{subject to} \quad A\mathbf{x} \leq \mathbf{b},\; \mathbf{x} \geq \mathbf{0},$$

where $\mathbf{x} \in \mathbb{R}^n$ is the decision vector, $\mathbf{c} \in \mathbb{R}^n$ is the objective coefficient vector, $A \in \mathbb{R}^{m \times n}$ is the constraint matrix, and $\mathbf{b} \in \mathbb{R}^m$ encodes resource limits. The feasible region $\mathcal{F} = \{\mathbf{x} : A\mathbf{x} \leq \mathbf{b},\, \mathbf{x} \geq \mathbf{0}\}$ is a convex polytope; an optimal solution, when it exists, always occurs at a vertex of this polytope.

Worked Example. A small bakery produces two goods: croissants ($x_1$) and muffins ($x_2$). Each croissant yields \$3 profit and requires 2 units of flour and 1 unit of butter. Each muffin yields \$4 profit and requires 1 unit of flour and 2 units of butter. Daily supplies are 100 units of flour and 80 units of butter. The LP is

$$\text{maximize} \quad 3x_1 + 4x_2$$ $$\text{subject to} \quad 2x_1 + x_2 \leq 100,\quad x_1 + 2x_2 \leq 80,\quad x_1, x_2 \geq 0.$$

Solving by finding the vertices of $\mathcal{F}$: the intersection of the two binding constraints gives $x_1 = 40,\; x_2 = 20$, yielding an objective value of $3(40)+4(20) = 200$. Checking all other vertices confirms this is the global maximum.

Key Theorem (Fundamental Theorem of Linear Programming). If a linear program has a bounded, non-empty feasible region, then an optimal solution exists and is attained at a vertex (extreme point) of the feasible polytope $\mathcal{F}$. This fact underlies the correctness of the Simplex algorithm, which traverses adjacent vertices along improving edges, terminating in finite time under non-degeneracy. In the worst case the Simplex method is exponential, but interior-point methods solve any LP in polynomial time $O(n^{3.5})$.

from sympy import symbols, Rational
from sympy.solvers.inequalities import reduce_rational_inequalities

# Verify the bakery corner point analytically
x1, x2 = symbols('x1 x2', nonneg=True)

# Binding constraints: 2x1 + x2 = 100, x1 + 2x2 = 80
from sympy import solve, Eq
sol = solve([Eq(2*x1 + x2, 100), Eq(x1 + 2*x2, 80)], [x1, x2])
profit = 3*sol[x1] + 4*sol[x2]
print(f"Optimal point: {sol}")   # {x1: 40, x2: 20}
print(f"Maximum profit: {profit}")  # 200
