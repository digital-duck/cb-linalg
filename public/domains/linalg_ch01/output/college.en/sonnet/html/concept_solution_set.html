Solution Set

Definition. Given an equation or system of equations in variables $x_1, x_2, \ldots, x_n$, the solution set is the collection of all $n$-tuples $(a_1, a_2, \ldots, a_n)$ that simultaneously satisfy every equation in the system. Formally, for a single equation $f(x) = 0$ over a domain $D$, the solution set is

$$S = \{ x \in D \mid f(x) = 0 \}.$$

For a system of $m$ equations $f_1(\mathbf{x}) = 0, \ldots, f_m(\mathbf{x}) = 0$, the solution set is the intersection of the individual solution sets:

$$S = \bigcap_{i=1}^{m} \{ \mathbf{x} \in D \mid f_i(\mathbf{x}) = 0 \}.$$

The solution set may be empty (no solution), finite, or infinite, depending on the structure of the system. An inconsistent system has $S = \emptyset$; a consistent system has $S \neq \emptyset$.

Worked Example. Consider the system over $\mathbb{R}^2$:

$$f_1: x + y = 4, \qquad f_2: x - y = 0.$$

From $f_2$ we obtain $x = y$. Substituting into $f_1$ gives $2x = 4$, so $x = 2$ and $y = 2$. The solution set is the single point $S = \{(2, 2)\}$. Geometrically, $f_1$ and $f_2$ define two lines in the plane that intersect at exactly one point; the solution set is that intersection.

Key Theorem (Dimension of the Solution Set for Linear Systems). Let $A\mathbf{x} = \mathbf{b}$ be a linear system with $A \in \mathbb{R}^{m \times n}$. If the system is consistent, then every solution can be written as $\mathbf{x} = \mathbf{x}_p + \mathbf{x}_h$, where $\mathbf{x}_p$ is any particular solution and $\mathbf{x}_h$ ranges over the null space $\ker(A)$. Consequently, $S = \mathbf{x}_p + \ker(A)$, an affine subspace of $\mathbb{R}^n$ of dimension $n - \operatorname{rank}(A)$.

Lab Cell.

from sympy import symbols, Eq, solve

x, y = symbols('x y')
system = [Eq(x + y, 4), Eq(x - y, 0)]
solution_set = solve(system, [x, y])
print(solution_set)   # {x: 2, y: 2}

Running this cell confirms $S = \{(2, 2)\}$. Modify the right-hand sides or add a third equation to observe how the solution set changes — try making the system inconsistent by replacing $x + y = 4$ with $x + y = 5$ while keeping $x - y = 0$ and a redundant equation $2x + 2y = 9$.
