收获

你已经学会了线性规划的核心思想：在一组线性约束条件下，寻找让某个目标函数取得最大值或最小值的解。用数学语言来说，就是在满足 $Ax \leq b$，$x \geq 0$ 的前提下，求 $\max\ c^T x$。这不只是一道练习题——它是现实世界中无数决策问题的通用语言。

线性规划之所以是这本书的终点，是因为它把前面所有的积木——变量、不等式、坐标平面、可行域——组合成了一套真正能"解决问题"的机器。你不再只是描述情况，而是在寻找最优答案。

这套工具打开了许多扇门。工厂经理用它来安排生产计划，在原料有限的情况下最大化利润；航空公司用它给数百条航线分配机组人员，同时压低成本；营养学家用它设计食谱，保证每种营养素达标而总热量最低；物流公司用它规划货车路线，让配送时间最短。每一个场景，背后都是同一个数学框架在运转。

记住一条简单的规律：最优解总是出现在可行域的某个顶点上。这意味着你不需要检查无穷多个点，只需要找到那几个"角落"，逐一比较目标函数的值，最大的那个就是答案。

课后练习

一家小面包房每天最多能用面粉 $60$ 千克、黄油 $30$ 千克。制作一个普通面包需要面粉 $2$ 千克、黄油 $0.5$ 千克，利润 $8$ 元；制作一个奶油蛋糕需要面粉 $1$ 千克、黄油 $1.5$ 千克，利润 $12$ 元。请写出这个问题的线性规划模型，并画出可行域，找出每天应各生产多少个才能使利润最大。

如果你对其中某个应用领域感兴趣——比如用线性规划设计你自己的"最优午餐菜单"——不妨选它深入探索，你会发现数学离生活从未如此之近。
