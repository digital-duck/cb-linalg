Function

Definition. A function $f$ from a set $A$ to a set $B$, written $f: A \to B$, is a rule that assigns to each element $x \in A$ exactly one element $f(x) \in B$. The set $A$ is the domain of $f$, the set $B$ is the codomain, and the range (or image) is $\{f(x) \mid x \in A\} \subseteq B$. The defining requirement — that every input produces exactly one output — distinguishes a function from a general relation. A relation $R \subseteq A \times B$ is a function if and only if for every $a \in A$ there exists a unique $b \in B$ such that $(a, b) \in R$.

Two functions $f$ and $g$ are equal if they share the same domain and codomain and satisfy $f(x) = g(x)$ for all $x$ in the domain. The expression $f$ refers to the function object itself; $f(x)$ refers to its value at a particular input $x$.

Worked Example. Let $f: \mathbb{R} \to \mathbb{R}$ be defined by $f(x) = x^2 - 3x + 2$. To evaluate $f$ at $x = 4$:

$$f(4) = (4)^2 - 3(4) + 2 = 16 - 12 + 2 = 6.$$

To find the range, we complete the square: $f(x) = \left(x - \tfrac{3}{2}\right)^2 - \tfrac{1}{4}$. Since the squared term is non-negative, $f(x) \geq -\tfrac{1}{4}$ for all $x \in \mathbb{R}$, and the minimum is attained at $x = \tfrac{3}{2}$. Hence the range is $\left[-\tfrac{1}{4}, \infty\right)$, which is a proper subset of the codomain $\mathbb{R}$.

Key Theorem (Composition). If $f: A \to B$ and $g: B \to C$, the composite function $g \circ f: A \to C$ defined by $(g \circ f)(x) = g(f(x))$ is itself a function. Composition is associative — $(h \circ g) \circ f = h \circ (g \circ f)$ — but generally not commutative: $g \circ f \neq f \circ g$.

Lab Cell.

from sympy import symbols, factor, solve

x = symbols('x')
f = x**2 - 3*x + 2

print("Factored form:", factor(f))          # (x-1)(x-2)
print("Zeros:", solve(f, x))                # [1, 2]
print("f(4) =", f.subs(x, 4))              # 6

Running this cell confirms the factorisation $(x-1)(x-2)$ and the zeros at $x = 1$ and $x = 2$, where the parabola crosses the horizontal axis.
