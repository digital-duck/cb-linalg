Vector Space

定义

向量空间（vector space）是代数结构的基石。设 $F$ 为一个域（field），$V$ 为一个非空集合，若 $V$ 上定义了加法 $+: V \times V \to V$ 与标量乘法 $\cdot: F \times V \to V$，并满足以下八条公理，则称 $(V, +, \cdot)$ 为域 $F$ 上的向量空间，$V$ 中的元素称为向量：

  • 加法结合律：$(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
  • 加法交换律：$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
  • 零元存在：存在 $\mathbf{0} \in V$，使得 $\mathbf{v} + \mathbf{0} = \mathbf{v}$
  • 逆元存在：对每个 $\mathbf{v}$，存在 $-\mathbf{v}$ 使得 $\mathbf{v} + (-\mathbf{v}) = \mathbf{0}$
  • 标量分配律 I：$a(\mathbf{u} + \mathbf{v}) = a\mathbf{u} + a\mathbf{v}$
  • 标量分配律 II：$(a + b)\mathbf{v} = a\mathbf{v} + b\mathbf{v}$
  • 标量结合律：$a(b\mathbf{v}) = (ab)\mathbf{v}$
  • 单位元：$1 \cdot \mathbf{v} = \mathbf{v}$

    • 具体例子

    考虑 $\mathbb{R}^2$，即所有实数对 $(x, y)$ 的集合，标量域取 $\mathbb{R}$。定义：

    $$ (x_1, y_1) + (x_2, y_2) = (x_1 + x_2,\ y_1 + y_2), \quad a \cdot (x, y) = (ax, ay) $$

    验证公理 3：零元为 $(0, 0)$，因为 $(x, y) + (0, 0) = (x, y)$。验证公理 5：

    $$ a\bigl((x_1, y_1) + (x_2, y_2)\bigr) = a(x_1+x_2,\ y_1+y_2) = (a(x_1+x_2),\ a(y_1+y_2)) = a(x_1,y_1) + a(x_2,y_2) $$

    其余公理验证类似，故 $\mathbb{R}^2$ 是 $\mathbb{R}$ 上的向量空间。

    核心定理

    定理（零向量唯一性）：向量空间 $V$ 中的零元 $\mathbf{0}$ 是唯一的。

    证明概要：设 $\mathbf{0}$ 与 $\mathbf{0}'$ 均为零元，则

    $$ \mathbf{0} = \mathbf{0} + \mathbf{0}' = \mathbf{0}' $$

    第一个等号由 $\mathbf{0}'$ 的零元性质得，第二个等号由 $\mathbf{0}$ 的零元性质得。$\square$

    实验单元（SymPy）

    from sympy import symbols, Matrix

# 在 ℝ² 中验证标量分配律
a = 3
u = Matrix([1, 2])
v = Matrix([4, -1])

lhs = a * (u + v)
rhs = a * u + a * v
print("左边:", lhs.T)
print("右边:", rhs.T)
print("公理成立:", lhs == rhs)  # 应输出 True

    运行上述代码，可直观验证 $a(\mathbf{u}+\mathbf{v})=a\mathbf{u}+a\mathbf{v}$ 在具体数值下成立，从而加深对抽象公理的直觉理解。
