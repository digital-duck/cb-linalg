Normal Matrix

Definition. A square matrix $A \in \mathbb{C}^{n \times n}$ is called normal if it commutes with its conjugate transpose:

$$A^*A = AA^*,$$

where $A^ = \bar{A}^\top$ denotes the conjugate transpose. Over $\mathbb{R}$, this reduces to $A^\top A = A A^\top$. The class of normal matrices is broad: every Hermitian matrix ($A^ = A$), skew-Hermitian matrix ($A^ = -A$), and unitary matrix ($A^A = I$) is normal.

Worked Example. Let

$$A = \begin{pmatrix} 2 & 1+i \\ 1-i & 3 \end{pmatrix}.$$

Compute $A^ = \begin{pmatrix} 2 & 1+i \\ 1-i & 3 \end{pmatrix}$. Since $A$ is Hermitian ($A^ = A$), it is automatically normal. Verify directly:

$$A^*A = A^2 = \begin{pmatrix} 2(2)+(1+i)(1-i) & \cdots \\ \cdots & \cdots \end{pmatrix} = AA^*. \checkmark$$

For a non-Hermitian normal example, take the rotation matrix $R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$. One verifies $R^\top R = I = RR^\top$, confirming normality.

Key Theorem (Spectral Theorem for Normal Matrices). A matrix $A \in \mathbb{C}^{n \times n}$ is normal if and only if it is unitarily diagonalisable: there exists a unitary matrix $U$ (satisfying $U^U = I$) such that*

$$A = U \Lambda U^*,$$

where $\Lambda = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$ contains the eigenvalues of $A$.

Proof sketch. The forward direction follows from Schur's theorem: every matrix is unitarily triangularisable as $A = UTU^$. If $A$ is normal, substituting into $A^A = AA^$ forces $T^T = TT^*$, which for upper-triangular $T$ implies $T$ is diagonal. $\square$

This theorem is foundational because orthonormal eigenvectors form a basis, making computations—particularly least-squares problems, operator exponentials, and stability analysis—tractable.

Lab Cell (SymPy).

from sympy import Matrix, I, eye

A = Matrix([[2, 1+I], [1-I, 3]])
Astar = A.conjugate().T

print("A*A =", Astar * A)
print("AA* =", A * Astar)
print("Normal?", Astar * A == A * Astar)

P, D = A.diagonalize()   # columns of P are eigenvectors
print("Eigenvalues:", D)
