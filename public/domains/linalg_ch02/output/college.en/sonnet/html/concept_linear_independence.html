Linear Independence

Definition. Let $V$ be a vector space over a field $\mathbb{F}$, and let $S = \{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\} \subset V$. The set $S$ is called linearly independent if the only solution to the equation

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \mathbf{0}$$

is the trivial solution $c_1 = c_2 = \cdots = c_k = 0$, where each $c_i \in \mathbb{F}$. If a non-trivial solution exists — that is, at least one $c_i \neq 0$ — then $S$ is called linearly dependent. Informally, a set is linearly independent when no vector in it can be expressed as a linear combination of the others.

Worked Example. Consider the vectors $\mathbf{v}_1 = (1, 0, 2)$, $\mathbf{v}_2 = (0, 1, -1)$, and $\mathbf{v}_3 = (2, -1, 5)$ in $\mathbb{R}^3$. To test independence, form the system $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + c_3\mathbf{v}_3 = \mathbf{0}$, which gives:

$$\begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & -1 \\ 2 & -1 & 5 \end{pmatrix} \begin{pmatrix} c_1 \\ c_2 \\ c_3 \end{pmatrix} = \mathbf{0}.$$

Row-reducing the coefficient matrix yields a row of zeros, revealing that $c_3$ is free. Setting $c_3 = 1$ gives $c_1 = -2$, $c_2 = 1$, confirming $-2\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0}$. The set is therefore linearly dependent.

Key Theorem. A set $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\} \subset \mathbb{R}^n$ is linearly independent if and only if the matrix $A = [\mathbf{v}_1 \mid \cdots \mid \mathbf{v}_k]$ has rank $k$ — equivalently, $A\mathbf{x} = \mathbf{0}$ has only the trivial solution. As a corollary, any set of $k > n$ vectors in $\mathbb{R}^n$ must be linearly dependent, since $A$ is tall and cannot have $k$ pivot columns.

Lab Cell (SymPy).

from sympy import Matrix

A = Matrix([[1, 0, 2],
            [0, 1,-1],
            [2,-1, 5]])

print("Rank:", A.rank())                  # 2 → dependent
print("Null space:", A.nullspace())       # non-trivial kernel vector

Running this cell confirms $\operatorname{rank}(A) = 2 < 3$, so the columns are linearly dependent. Replacing $\mathbf{v}_3$ with $(1, 1, 0)$ raises the rank to 3 and empties the null space, yielding an independent set — an experiment worth trying directly in the lab.
