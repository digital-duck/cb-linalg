Linear Combination

Definition. Let $V$ be a vector space over a field $\mathbb{F}$, and let $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\} \subset V$ be a finite collection of vectors. A linear combination of these vectors is any expression of the form

$$\mathbf{w} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k = \sum_{i=1}^{k} c_i\mathbf{v}_i,$$

where the coefficients $c_1, c_2, \ldots, c_k \in \mathbb{F}$ are scalars chosen freely. The resulting vector $\mathbf{w}$ is said to be expressible as a linear combination of $\mathbf{v}_1, \ldots, \mathbf{v}_k$. When $\mathbb{F} = \mathbb{R}$ this construction captures the geometric idea of scaling and adding directed arrows in $\mathbb{R}^n$.

Worked Example. Let $\mathbf{v}_1 = (1, 0, 2)$ and $\mathbf{v}_2 = (0, 1, -1)$ in $\mathbb{R}^3$. Set $c_1 = 3$ and $c_2 = -2$. Then

$$\mathbf{w} = 3(1,0,2) + (-2)(0,1,-1) = (3,0,6) + (0,-2,2) = (3,-2,8).$$

Now ask whether $\mathbf{u} = (3, -2, 5)$ is also a linear combination of $\mathbf{v}_1$ and $\mathbf{v}_2$. Solving $c_1(1,0,2) + c_2(0,1,-1) = (3,-2,5)$ yields the system $c_1 = 3$, $c_2 = -2$, and $2c_1 - c_2 = 5$, i.e.\ $8 \neq 5$. The system is inconsistent, so $\mathbf{u}$ is not a linear combination of $\mathbf{v}_1$ and $\mathbf{v}_2$.

Key Theorem (Characterisation via span). The set of all linear combinations of $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ forms a subspace of $V$, called the span:

$$\operatorname{span}\{\mathbf{v}_1, \ldots, \mathbf{v}_k\} = \left\{\, \sum_{i=1}^{k} c_i\mathbf{v}_i \;\middle|\; c_i \in \mathbb{F} \,\right\}.$$

Proof sketch. Closure under addition: $(c_i\mathbf{v}_i) + (d_i\mathbf{v}_i) = (c_i+d_i)\mathbf{v}_i$, which remains a linear combination. Closure under scalar multiplication is immediate. The zero vector arises by setting all $c_i = 0$. Hence all three subspace axioms hold. $\square$

Lab Cell (SymPy).

from sympy import Matrix, symbols

c1, c2 = symbols('c1 c2')
v1 = Matrix([1, 0, 2])
v2 = Matrix([0, 1, -1])
u  = Matrix([3, -2, 5])

A   = Matrix([[1, 0], [0, 1], [2, -1]])   # columns are v1, v2
sol = A.solve_least_squares(u)            # least-squares attempt
residual = A * sol - u
print("Residual:", residual)              # non-zero ⟹ u not in span{v1,v2}
