Orthogonal Set

Definition. Let $V$ be an inner product space over $\mathbb{R}$ (or $\mathbb{C}$) with inner product $\langle \cdot, \cdot \rangle$. A set of vectors $S = \{v_1, v_2, \ldots, v_n\} \subset V$ is called an orthogonal set if every pair of distinct vectors in $S$ is orthogonal, that is,

$$\langle v_i, v_j \rangle = 0 \quad \text{for all } i \neq j.$$

If, additionally, each vector has unit norm ($\|v_i\| = 1$ for all $i$), the set is called orthonormal. Every orthogonal set of nonzero vectors is linearly independent, making orthogonal sets particularly powerful as bases.

Worked Example. Consider $\mathbb{R}^3$ with the standard dot product. Verify that $S = \{v_1, v_2, v_3\}$, where

$$v_1 = \begin{pmatrix}1\\1\\0\end{pmatrix}, \quad v_2 = \begin{pmatrix}1\\-1\\0\end{pmatrix}, \quad v_3 = \begin{pmatrix}0\\0\\1\end{pmatrix},$$

forms an orthogonal set. Computing each inner product:

$$\langle v_1, v_2 \rangle = (1)(1)+(1)(-1)+(0)(0) = 0,$$ $$\langle v_1, v_3 \rangle = (1)(0)+(1)(0)+(0)(1) = 0,$$ $$\langle v_2, v_3 \rangle = (1)(0)+(-1)(0)+(0)(1) = 0.$$

All pairwise inner products vanish, so $S$ is orthogonal. To normalize, divide each vector by its norm: $\|v_1\| = \|v_2\| = \sqrt{2}$ and $\|v_3\| = 1$, yielding the orthonormal set $\left\{\tfrac{v_1}{\sqrt{2}},\, \tfrac{v_2}{\sqrt{2}},\, v_3\right\}$.

Key Theorem (Orthogonal Expansion). Let $\{v_1, \ldots, v_n\}$ be an orthogonal basis for a subspace $W \subseteq V$. For any $w \in W$,

$$w = \sum_{i=1}^{n} \frac{\langle w, v_i \rangle}{\langle v_i, v_i \rangle}\, v_i.$$

Proof sketch. Write $w = \sum c_i v_i$. Taking the inner product of both sides with $v_k$ and using orthogonality eliminates all terms $i \neq k$, giving $c_k = \langle w, v_k \rangle / \langle v_k, v_k \rangle$. $\square$

This formula bypasses Gaussian elimination entirely, reducing coordinate extraction to scalar products.

from sympy import Matrix, sqrt, Rational

v1 = Matrix([1, 1, 0])
v2 = Matrix([1, -1, 0])
v3 = Matrix([0, 0, 1])

pairs = [(v1, v2), (v1, v3), (v2, v3)]
for a, b in pairs:
    print(f"<{a.T},{b.T}> = {a.dot(b)}")   # should all print 0

# Normalize
for v in [v1, v2, v3]:
    norm = sqrt(v.dot(v))
    print(f"unit vector: {v.T / norm}")
