Gram Schmidt Procedure

Definition. Let $V$ be an inner product space and let $\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ be a linearly independent set of vectors in $V$. The Gram–Schmidt procedure is an algorithm that produces an orthogonal set $\{\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_n\}$ spanning the same subspace. Explicitly, define

$$\mathbf{u}_1 = \mathbf{v}_1,$$

and for $k = 2, 3, \ldots, n$,

$$\mathbf{u}_k = \mathbf{v}_k - \sum_{j=1}^{k-1} \frac{\langle \mathbf{v}_k, \mathbf{u}_j \rangle}{\langle \mathbf{u}_j, \mathbf{u}_j \rangle}\,\mathbf{u}_j.$$

Each subtracted term is the orthogonal projection of $\mathbf{v}_k$ onto $\mathbf{u}_j$; removing these projections strips away every component of $\mathbf{v}_k$ that lies along a previously constructed basis vector. Normalising each $\mathbf{u}_k$ yields an orthonormal basis, commonly denoted $\{\mathbf{e}_k\}$.

Worked example. Let $\mathbf{v}_1 = (1, 1, 0)^\top$ and $\mathbf{v}_2 = (1, 0, 1)^\top$ in $\mathbb{R}^3$ with the standard inner product.

Set $\mathbf{u}_1 = (1, 1, 0)^\top$. Then

$$\frac{\langle \mathbf{v}_2, \mathbf{u}_1 \rangle}{\langle \mathbf{u}_1, \mathbf{u}_1 \rangle} = \frac{1 \cdot 1 + 0 \cdot 1 + 1 \cdot 0}{1^2 + 1^2 + 0^2} = \frac{1}{2},$$

so

$$\mathbf{u}_2 = \begin{pmatrix}1\\0\\1\end{pmatrix} - \frac{1}{2}\begin{pmatrix}1\\1\\0\end{pmatrix} = \begin{pmatrix}1/2\\-1/2\\1\end{pmatrix}.$$

One verifies directly that $\langle \mathbf{u}_1, \mathbf{u}_2 \rangle = \tfrac{1}{2} - \tfrac{1}{2} + 0 = 0$. $\checkmark$

Key theorem. If $\{\mathbf{v}_1, \ldots, \mathbf{v}_n\}$ is linearly independent, the Gram–Schmidt procedure terminates in exactly $n$ steps and produces a basis $\{\mathbf{u}_1, \ldots, \mathbf{u}_n\}$ satisfying $\langle \mathbf{u}_i, \mathbf{u}_j \rangle = 0$ for all $i \neq j$, with $\operatorname{span}\{\mathbf{u}_1, \ldots, \mathbf{u}_k\} = \operatorname{span}\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ for every $k$. This is the existence half of the QR decomposition: writing $Q = [\mathbf{e}_1 \mid \cdots \mid \mathbf{e}_n]$ and $R_{jk} = \langle \mathbf{v}_k, \mathbf{e}_j \rangle$ gives $A = QR$ with $Q$ orthogonal and $R$ upper triangular.

Lab cell.

from sympy import Matrix, GramSchmidt, pprint

vecs = [Matrix([1, 1, 0]), Matrix([1, 0, 1])]
ortho = GramSchmidt(vecs, orthonormal=True)
for i, e in enumerate(ortho, 1):
    pprint(f"e_{i} ="); pprint(e)

Running this cell reproduces the worked example and displays the normalised vectors $\mathbf{e}_1 = \tfrac{1}{\sqrt{2}}(1,1,0)^\top$ and $\mathbf{e}_2 = \tfrac{1}{\sqrt{6}}(1,-1,2)^\top$.
