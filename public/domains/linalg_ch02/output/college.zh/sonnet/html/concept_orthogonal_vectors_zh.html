Orthogonal Vectors

定义。 设 $\mathbf{u}, \mathbf{v} \in \mathbb{R}^n$。若二者的内积（点积）满足

$$\mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^{n} u_i v_i = 0,$$

则称 $\mathbf{u}$ 与 $\mathbf{v}$ 正交（orthogonal），记作 $\mathbf{u} \perp \mathbf{v}$。零向量与任意向量正交，但通常在讨论正交基时将其排除。若两向量既正交又均为单位向量（$\|\mathbf{u}\| = \|\mathbf{v}\| = 1$），则称它们标准正交（orthonormal）。

例题。 验证 $\mathbf{u} = (3, -2, 1)^\top$ 与 $\mathbf{v} = (2, 4, 4)^\top$ 是否正交。

$$\mathbf{u} \cdot \mathbf{v} = 3 \times 2 + (-2) \times 4 + 1 \times 4 = 6 - 8 + 4 = 2.$$

结果不为零，故两向量不正交。若将 $\mathbf{v}$ 改为 $\mathbf{v}' = (2, 4, -2)^\top$，则

$$\mathbf{u} \cdot \mathbf{v}' = 6 - 8 + (-2) = -4 \neq 0,$$

再令 $\mathbf{v}'' = (2, 4, 2)^\top$：$3(2)+(-2)(4)+1(2)=6-8+2=0$。故 $\mathbf{u} \perp \mathbf{v}''$，验证完毕。

核心定理（勾股定理的向量推广）。 若 $\mathbf{u} \perp \mathbf{v}$，则

$$\|\mathbf{u} + \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2.$$

证明概要。 展开左侧：

$$\|\mathbf{u} + \mathbf{v}\|^2 = (\mathbf{u}+\mathbf{v})\cdot(\mathbf{u}+\mathbf{v}) = \|\mathbf{u}\|^2 + 2(\mathbf{u}\cdot\mathbf{v}) + \|\mathbf{v}\|^2.$$

由正交性 $\mathbf{u}\cdot\mathbf{v}=0$，中间项消失，即得结论。$\blacksquare$

此定理表明，正交性是经典直角三角形勾股关系在任意维度空间中的自然延伸。

实验单元（SymPy）。

from sympy.matrices import Matrix

u = Matrix([3, -2, 1])
v = Matrix([2,  4,  2])

dot = u.dot(v)
print("内积:", dot)                          # 0 → 正交
print("勾股验证:", u.norm()**2 + v.norm()**2 == (u + v).norm()**2)

运行上述代码，若输出 内积: 0 且勾股验证为 True，则数值层面证实了 $\mathbf{u} \perp \mathbf{v}$ 及相应定理。读者可自行修改分量，观察内积何时为零，从而建立对正交条件的直觉认识。
