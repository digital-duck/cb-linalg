Complex Number

定义

复数（complex number）是形如

$$z = a + bi$$

的数，其中 $a, b \in \mathbb{R}$，$i$ 为虚数单位，满足 $i^2 = -1$。称 $a = \operatorname{Re}(z)$ 为实部，$b = \operatorname{Im}(z)$ 为虚部。全体复数构成的集合记作 $\mathbb{C}$。当 $b = 0$ 时，$z$ 退化为实数；当 $a = 0, b \neq 0$ 时，$z$ 称为纯虚数。复数 $z$ 的共轭定义为 $\bar{z} = a - bi$，其模定义为

$$|z| = \sqrt{a^2 + b^2}.$$

在复平面（Argand 平面）中，$z$ 对应点 $(a, b)$，实轴对应实部，虚轴对应虚部。

计算示例

设 $z_1 = 3 + 4i$，$z_2 = 1 - 2i$，求 $z_1 z_2$ 及 $|z_1|$。

$$z_1 z_2 = (3)(1) + (3)(-2i) + (4i)(1) + (4i)(-2i)$$ $$= 3 - 6i + 4i - 8i^2 = 3 - 2i + 8 = 11 - 2i.$$ $$|z_1| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5.$$

可见复数乘法遵循分配律，且每次将 $i^2$ 替换为 $-1$。

关键定理

欧拉公式（Euler's formula）建立了复数与三角函数之间最深刻的联系：

$$e^{i\theta} = \cos\theta + i\sin\theta, \quad \theta \in \mathbb{R}.$$

由此，任意复数均可写成极坐标形式 $z = r e^{i\theta}$，其中 $r = |z|$，$\theta = \arg(z)$。乘法在极坐标下尤为简洁：

$$z_1 z_2 = r_1 r_2\, e^{i(\theta_1 + \theta_2)},$$

即模相乘、辐角相加。取 $\theta = \pi$ 即得著名的欧拉恒等式 $e^{i\pi} + 1 = 0$。

实验单元（SymPy）

from sympy import *

z1 = 3 + 4*I
z2 = 1 - 2*I

print("乘积:", expand(z1 * z2))          # 11 - 2*I
print("模  :", Abs(z1))                   # 5
print("共轭:", conjugate(z1))             # 3 - 4*I

theta = symbols('theta', real=True)
print("欧拉公式验证:", simplify(exp(I*theta) - (cos(theta) + I*sin(theta))))  # 0

运行上述代码，验证符号计算与手算结果完全一致，并观察 SymPy 如何在内部保持精确的有理数与符号形式。
