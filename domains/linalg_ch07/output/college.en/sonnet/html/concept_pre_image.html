Pre Image

Definition. Let $f : X \to Y$ be a function between sets $X$ and $Y$. For any subset $B \subseteq Y$, the pre-image (or inverse image) of $B$ under $f$ is the set

$$f^{-1}(B) = \{ x \in X \mid f(x) \in B \}.$$

Note carefully that $f^{-1}(B)$ is defined for every function $f$, regardless of whether $f$ possesses an inverse function. The notation reuses the superscript $-1$, but here it denotes an operation on subsets of the codomain, not a functional inverse. When $B = \{y\}$ is a singleton, $f^{-1}(\{y\})$ is called the fiber of $f$ over $y$.

Worked Example. Define $f : \mathbb{R} \to \mathbb{R}$ by $f(x) = x^2$, and let $B = [1, 4]$. We seek $f^{-1}(B)$, the set of all real numbers whose square lies between $1$ and $4$:

$$f^{-1}([1,4]) = \{ x \in \mathbb{R} \mid 1 \le x^2 \le 4 \} = [-2,-1] \cup [1,2].$$

Observe that $f$ is not injective, so two disjoint intervals map onto the same interval in the codomain. Taking instead $B = \{-1\}$: since $x^2 \ge 0$ for all real $x$, we get $f^{-1}(\{-1\}) = \emptyset$, illustrating that the pre-image of a set outside the range is empty.

Key Theorem (Pre-image preserves set operations). Let $f : X \to Y$ and let $\{B_\alpha\}$ be an indexed family of subsets of $Y$. Then:

$$f^{-1}\!\left(\bigcup_\alpha B_\alpha\right) = \bigcup_\alpha f^{-1}(B_\alpha), \qquad f^{-1}\!\left(\bigcap_\alpha B_\alpha\right) = \bigcap_\alpha f^{-1}(B_\alpha),$$ $$f^{-1}(Y \setminus B) = X \setminus f^{-1}(B).$$

Proof sketch. Each identity follows from chasing definitions. For the union: $x \in f^{-1}(\bigcup_\alpha B_\alpha)$ iff $f(x) \in B_\alpha$ for some $\alpha$, iff $x \in f^{-1}(B_\alpha)$ for some $\alpha$. The intersection and complement cases are analogous. $\square$

This theorem is fundamental in topology, where continuity of $f$ is defined precisely by requiring that pre-images of open sets are open.

Lab Cell.

from sympy import symbols, S, Interval, Union, solveset, oo

x = symbols('x', real=True)
f = x**2
B = Interval(1, 4)

# Solve f(x) in B, i.e. 1 <= x^2 <= 4
lower = solveset(f - B.start >= 0, x, domain=S.Reals)
upper = solveset(f - B.end <= 0, x, domain=S.Reals)
preimage = lower.intersect(upper)
print("Pre-image of [1,4] under x²:", preimage)
# Expected: Union(Interval(-2, -1), Interval(1, 2))
