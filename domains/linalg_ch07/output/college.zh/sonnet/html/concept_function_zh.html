函数

定义。 设 $A$ 与 $B$ 为两个非空集合。若存在一个规则 $f$，使得对 $A$ 中的每一个元素 $x$，都有 $B$ 中唯一确定的元素 $y$ 与之对应，则称 $f$ 为从 $A$ 到 $B$ 的一个函数（function），记作

$$f: A \to B, \quad x \mapsto f(x).$$

集合 $A$ 称为 $f$ 的定义域（domain），记作 $\operatorname{dom}(f)$；集合 $\{f(x) \mid x \in A\}$ 称为 $f$ 的值域（range），记作 $\operatorname{ran}(f) \subseteq B$。需特别强调"唯一性"：同一个 $x$ 不可对应两个不同的 $y$；否则该规则不构成函数。

例题。 考察规则 $f(x) = x^2 - 2x + 3$，定义域取 $A = \mathbb{R}$。

  • 验证为函数： 对任意实数 $x$，表达式 $x^2 - 2x + 3$ 给出唯一实数值，故 $f$ 是函数。
  • 求函数值： $f(0) = 0 - 0 + 3 = 3$；$f(2) = 4 - 4 + 3 = 3$；$f(-1) = 1 + 2 + 3 = 6$。
  • 确定值域： 配方得 $f(x) = (x-1)^2 + 2 \geq 2$，且等号在 $x=1$ 时成立，故 $\operatorname{ran}(f) = [2, +\infty)$。

    • 基本定理（函数相等）。 设 $f: A \to B$ 与 $g: C \to B$ 为两个函数。$f = g$ 当且仅当：

    $$\operatorname{dom}(f) = \operatorname{dom}(g) \quad \text{且} \quad \forall\, x \in A,\ f(x) = g(x).$$

    证明思路： 若 $\operatorname{dom}(f) \neq \operatorname{dom}(g)$，则存在某 $x_0$ 仅属于其中一个定义域，对应值无从比较，故两函数必然不同。当定义域相等时，逐点比较函数值即可完成判定。$\square$

    实验单元（SymPy）。

    from sympy import symbols, factor, solve, oo, S

x = symbols('x')
f = x**2 - 2*x + 3

# 配方与最小值
completed = factor(f - 2) + 2          # (x-1)^2 + 2
minimum   = solve(f.diff(x), x)        # [1]

# 值域下界验证
print("最小值点:", minimum)            # [1]
print("最小值:  ", f.subs(x, 1))      # 2

    运行上述代码，SymPy 将返回最小值点 $x=1$ 及最小值 $2$，与手工计算完全吻合，从而验证值域为 $[2,+\infty)$。
