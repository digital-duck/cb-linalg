解集

定义. 设 $f_1, f_2, \ldots, f_m$ 为定义在集合 $X$ 上的函数，条件 $P(x)$ 为由这些函数构成的命题。方程组（或不等式组）的解集（solution set）定义为使 $P(x)$ 成立的所有元素构成的集合：

$$S = \{ x \in X \mid P(x) \text{ 为真} \}.$$

解集是集合论与代数的交汇点：它将"满足条件"这一逻辑概念转化为集合的语言，使得集合运算（交、并、补）可直接用于描述联立方程组与不等式系统的解结构。

例题. 求以下联立方程组在 $\mathbb{R}$ 上的解集：

$$\begin{cases} x^2 - 5x + 6 = 0, \\ x < 3. \end{cases}$$

第一步：对二次方程分解因式：

$$x^2 - 5x + 6 = (x-2)(x-3) = 0 \implies x = 2 \text{ 或 } x = 3.$$

故第一个条件的解集为 $S_1 = \{2, 3\}$。

第二步：不等式 $x < 3$ 的解集为 $S_2 = (-\infty, 3)$。

第三步：联立条件等价于取交集：

$$S = S_1 \cap S_2 = \{2, 3\} \cap (-\infty, 3) = \{2\}.$$

因此，满足所有条件的解集为 $S = \{2\}$。

关键定理（解集的单调性）. 设 $P(x)$ 与 $Q(x)$ 均为定义在 $X$ 上的条件，则：

$$P(x) \implies Q(x) \iff S_P \subseteq S_Q.$$

证明纲要：若 $P(x) \implies Q(x)$，则对任意 $x \in S_P$，有 $P(x)$ 为真，从而 $Q(x)$ 为真，即 $x \in S_Q$，故 $S_P \subseteq S_Q$。反之亦然。$\blacksquare$

该定理揭示了逻辑蕴含与集合包含之间的深刻对应，是后续研究等价方程（$S_P = S_Q$）的理论基础。

实验单元（SymPy）.

from sympy import symbols, solve, S as SymS
x = symbols('x')

S1 = set(solve(x**2 - 5*x + 6, x))          # {2, 3}
S2 = set(filter(lambda v: v < 3, S1))        # 施加不等式约束

print("解集 S =", S2)                        # 输出: {2}
