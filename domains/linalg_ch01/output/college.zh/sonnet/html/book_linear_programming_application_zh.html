线性规划的应用标志着本书学习旅程的自然终点。在此之前，我们依次建立了向量空间的几何直觉、线性方程组的代数结构、矩阵的变换语言，以及凸集与超平面的拓扑基础。线性规划将这一切汇聚为一个统一的决策框架：在有限资源的约束下，寻找使目标函数取得最优值的可行解。

定义（标准型线性规划）。 设 $\mathbf{c} \in \mathbb{R}^n$，$A \in \mathbb{R}^{m \times n}$，$\mathbf{b} \in \mathbb{R}^m$。标准型线性规划问题为

$$\min_{\mathbf{x} \in \mathbb{R}^n} \mathbf{c}^\top \mathbf{x} \quad \text{使得} \quad A\mathbf{x} = \mathbf{b},\; \mathbf{x} \geq \mathbf{0}.$$

可行域 $\mathcal{F} = \{\mathbf{x} \mid A\mathbf{x} = \mathbf{b},\, \mathbf{x} \geq \mathbf{0}\}$ 是一个凸多面体，而最优解（若存在）必定出现在其顶点之一。

具体例子。 某工厂生产甲、乙两种产品，每单位利润分别为 $5$ 元和 $4$ 元。生产甲消耗原料 $6$ 单位、工时 $1$ 小时；生产乙消耗原料 $4$ 单位、工时 $2$ 小时。原料上限为 $240$ 单位，工时上限为 $50$ 小时。设甲产量为 $x_1$，乙产量为 $x_2$，则

$$\max\; 5x_1 + 4x_2 \quad \text{使得} \quad 6x_1 + 4x_2 \leq 240,\; x_1 + 2x_2 \leq 50,\; x_1, x_2 \geq 0.$$

枚举可行域的四个顶点：$(0,0)$、$(40,0)$、$(30,5)$、$(0,25)$，目标函数值依次为 $0$、$200$、$170$、$100$。最优解为 $x_1 = 40,\, x_2 = 0$，最大利润 $200$ 元。

关键定理（单纯形法的有限性）。 设可行域非空且有界，则单纯形法在有限步内到达最优顶点。其核心思路在于：每次迭代沿某条棱从一个顶点移向相邻顶点，目标函数值严格不增（或不减），而顶点数有限，故算法必然终止。

# SymPy 实验单元
from sympy import symbols, Rational
from scipy.optimize import linprog

c = [-5, -4]                          # 最大化 → 取负
A = [[6, 4], [1, 2]]
b = [240, 50]
bounds = [(0, None), (0, None)]
res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs')
print(f"最优解: x1={res.x[0]:.1f}, x2={res.x[1]:.1f}, 最大利润={-res.fun:.1f} 元")

线性规划的威力在于其普适性：无论是供应链中的运输成本最小化、金融组合的收益最大化、医疗资源的公平分配，还是机器学习中支持向量机的间隔优化，其本质都是在线性约束下的最优化。每一个应用领域都是同一数学骨架的不同皮肤。
