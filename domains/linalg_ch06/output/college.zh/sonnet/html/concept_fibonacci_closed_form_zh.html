Fibonacci 闭合公式

定义。 Fibonacci 数列 $\{F_n\}$ 由以下递推关系定义：

$$F_0 = 0,\quad F_1 = 1,\quad F_n = F_{n-1} + F_{n-2},\quad n \geq 2.$$

所谓闭合公式（closed-form expression），是指用有限次初等运算直接表示 $F_n$ 的显式表达式，无需递推计算。Binet 公式给出了这样的表达式：

$$F_n = \frac{\varphi^n - \psi^n}{\sqrt{5}},$$

其中黄金比例 $\varphi = \dfrac{1+\sqrt{5}}{2}$，其共轭根 $\psi = \dfrac{1-\sqrt{5}}{2}$。

推导概要。 令 $F_n = r^n$，代入递推关系得特征方程

$$r^2 = r + 1 \implies r^2 - r - 1 = 0,$$

两根恰为 $\varphi$ 与 $\psi$。一般解为

$$F_n = A\varphi^n + B\psi^n.$$

代入初始条件 $F_0 = 0$，$F_1 = 1$，解方程组得

$$A = \frac{1}{\sqrt{5}},\quad B = -\frac{1}{\sqrt{5}},$$

从而 Binet 公式成立。$\square$

计算示例。 计算 $F_{10}$。

$$\varphi = \frac{1+\sqrt{5}}{2} \approx 1.61803,\quad \psi = \frac{1-\sqrt{5}}{2} \approx -0.61803.$$ $$F_{10} = \frac{(1.61803)^{10} - (-0.61803)^{10}}{\sqrt{5}} \approx \frac{122.9919 - 0.0081}{2.2361} \approx \frac{122.9838}{2.2361} = 55.$$

与递推结果完全一致。

关键定理。 由于 $|\psi| < 1$，当 $n \to \infty$ 时 $\psi^n \to 0$，故

$$F_n = \left\lfloor \frac{\varphi^n}{\sqrt{5}} + \frac{1}{2} \right\rfloor,\quad n \geq 0,$$

即 $F_n$ 是最接近 $\dfrac{\varphi^n}{\sqrt{5}}$ 的整数。这一结论揭示了 Fibonacci 数列与黄金比例之间深刻的代数联系。

实验单元（SymPy）

from sympy import sqrt, Rational, simplify, fibonacci, symbols

phi = (1 + sqrt(5)) / 2
psi = (1 - sqrt(5)) / 2

def binet(n):
    return simplify((phi**n - psi**n) / sqrt(5))

# 验证前10项
for n in range(11):
    assert binet(n) == fibonacci(n), f"第{n}项不匹配"

print("Binet 公式验证通过，前11项全部正确。")
