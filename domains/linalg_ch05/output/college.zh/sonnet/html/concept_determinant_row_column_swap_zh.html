Determinant Row Column Swap

定义

设 $A$ 为 $n \times n$ 矩阵。若将 $A$ 的任意两行（或两列）互换，所得矩阵 $B$ 的行列式满足

$$\det(B) = -\det(A).$$

更精确地说，设 $E_{ij}$ 为对应于"交换第 $i$ 行与第 $j$ 行"的初等矩阵（$i \neq j$），则

$$\det(E_{ij} A) = \det(E_{ij})\,\det(A) = (-1)\,\det(A).$$

这一性质是行列式的反对称性（alternating property）的直接体现：行列式关于任意两个自变量（行向量或列向量）具有交错性。

具体例子

取

$$A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}, \qquad \det(A) = 1\cdot4 - 2\cdot3 = -2.$$

将第一行与第二行互换，得

$$B = \begin{pmatrix} 3 & 4 \\ 1 & 2 \end{pmatrix}, \qquad \det(B) = 3\cdot2 - 4\cdot1 = 2 = -(-2).$$

结果恰好验证 $\det(B) = -\det(A)$。对列的互换同理：将 $A$ 的第一列与第二列互换得

$$C = \begin{pmatrix} 2 & 1 \\ 4 & 3 \end{pmatrix}, \qquad \det(C) = 2\cdot3 - 1\cdot4 = 2 = -\det(A).$$

关键定理

定理（反对称性推论）：若矩阵 $A$ 有两行（或两列）完全相同，则 $\det(A) = 0$。

证明思路：设第 $i$ 行与第 $j$ 行相同，互换这两行后矩阵不变，即 $B = A$，故 $\det(B) = \det(A)$。但由行交换性质知 $\det(B) = -\det(A)$，因此 $\det(A) = -\det(A)$，从而 $\det(A) = 0$。$\blacksquare$

此定理在判断矩阵奇异性及化简行列式计算中极为常用。

实验单元（SymPy）

from sympy import Matrix

A = Matrix([[1, 2], [3, 4]])
B = Matrix([[3, 4], [1, 2]])  # 交换第一行与第二行

print("det(A) =", A.det())   # 输出 -2
print("det(B) =", B.det())   # 输出  2
print("验证:", B.det() == -A.det())  # 输出 True

# 两行相同的情形
C = Matrix([[1, 2], [1, 2]])
print("det(C) =", C.det())   # 输出 0

运行以上代码，可直观确认行交换将行列式变号，以及重复行导致行列式为零的结论。
