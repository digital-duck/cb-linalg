Relation Of Linear Dependence

定义

设 $V$ 为数域 $\mathbb{F}$ 上的向量空间，$\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_k\} \subset V$ 为一组向量。若存在不全为零的标量 $c_1, c_2, \ldots, c_k \in \mathbb{F}$，使得

$$c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k = \mathbf{0},$$

则称该方程为这组向量的一个线性相关关系（relation of linear dependence），并称这组向量线性相关。若上式仅在所有系数均为零时成立，则称这组向量线性无关。

关键之处在于"不全为零"这一条件：零向量组合平凡地等于零，无任何信息量。线性相关关系捕捉的是向量之间非平凡的线性约束。

具体例子

考虑 $\mathbb{R}^3$ 中的三个向量：

$$\mathbf{v}_1 = \begin{pmatrix}1\\0\\2\end{pmatrix},\quad \mathbf{v}_2 = \begin{pmatrix}0\\1\\-1\end{pmatrix},\quad \mathbf{v}_3 = \begin{pmatrix}2\\-1\\5\end{pmatrix}.$$

令 $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + c_3\mathbf{v}_3 = \mathbf{0}$，写出分量方程：

$$\begin{cases} c_1 + 2c_3 = 0 \\ c_2 - c_3 = 0 \\ 2c_1 - c_2 + 5c_3 = 0 \end{cases}$$

取 $c_3 = 1$，则 $c_1 = -2$，$c_2 = 1$。验证：$-2\mathbf{v}_1 + \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0}$。因此 $\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$ 线性相关，$\mathbf{v}_3 = 2\mathbf{v}_1 - \mathbf{v}_2$ 可由前两者线性表示。

核心定理

定理（线性相关的等价刻画）：向量组 $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$（$k \geq 2$）线性相关，当且仅当其中至少有一个向量可以写成其余向量的线性组合。

证明思路：若存在线性相关关系 $\sum_{i=1}^k c_i \mathbf{v}_i = \mathbf{0}$ 且某个 $c_j \neq 0$，则 $\mathbf{v}_j = -c_j^{-1}\sum_{i \neq j} c_i \mathbf{v}_i$，即 $\mathbf{v}_j$ 可由其余向量线性表示。反之亦然。$\blacksquare$

实验单元（SymPy）

from sympy import Matrix

# 验证上述例子的线性相关关系
A = Matrix([[1, 0, 2],
            [0, 1, -1],
            [2, -1, 5]])

# 求零空间：非零解即为线性相关关系的系数向量
null = A.nullspace()
print("零空间基向量：", null)
# 输出应为 [Matrix([-2, 1, 1])]，对应 c1=-2, c2=1, c3=1

运行上述代码，nullspace() 返回非空集合，直接证实这三个向量线性相关，并给出具体的关系系数。
