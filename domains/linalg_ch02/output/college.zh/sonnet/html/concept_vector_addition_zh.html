向量加法

定义。 设 $\mathbf{u} = (u_1, u_2, \ldots, u_n)$ 与 $\mathbf{v} = (v_1, v_2, \ldots, v_n)$ 为 $n$ 维实向量空间 $\mathbb{R}^n$ 中的两个向量。它们的向量和定义为逐分量相加：

$$ \mathbf{u} + \mathbf{v} = (u_1 + v_1,\ u_2 + v_2,\ \ldots,\ u_n + v_n). $$

几何上，向量加法遵循平行四边形法则：将 $\mathbf{v}$ 的起点平移至 $\mathbf{u}$ 的终点，连接原点与新终点所得的向量即为 $\mathbf{u} + \mathbf{v}$。

具体例子。 设 $\mathbf{u} = (3, -1, 2)$，$\mathbf{v} = (-1, 4, 5)$，均属于 $\mathbb{R}^3$。按定义逐分量计算：

$$ \mathbf{u} + \mathbf{v} = (3 + (-1),\ -1 + 4,\ 2 + 5) = (2, 3, 7). $$

可验证：$\|\mathbf{u} + \mathbf{v}\| = \sqrt{4 + 9 + 49} = \sqrt{62} \approx 7.87$，而 $\|\mathbf{u}\| + \|\mathbf{v}\| = \sqrt{14} + \sqrt{42} \approx 10.23$，符合三角不等式 $\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$。

关键定理（向量加法的基本性质）。 对任意 $\mathbf{u}, \mathbf{v}, \mathbf{w} \in \mathbb{R}^n$，向量加法满足以下四条公理：

  • 封闭性：$\mathbf{u} + \mathbf{v} \in \mathbb{R}^n$；
  • 交换律：$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$；
  • 结合律：$(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$；
  • 零元与逆元存在：存在唯一的零向量 $\mathbf{0}$ 使得 $\mathbf{u} + \mathbf{0} = \mathbf{u}$，且存在 $-\mathbf{u}$ 使得 $\mathbf{u} + (-\mathbf{u}) = \mathbf{0}$。

    • 证明概要。 交换律与结合律直接由实数加法的对应性质推导，逐分量验证即可；零向量为 $\mathbf{0} = (0, 0, \ldots, 0)$，逆向量为 $-\mathbf{u} = (-u_1, -u_2, \ldots, -u_n)$。这四条公理使 $(\mathbb{R}^n, +)$ 构成一个阿贝尔群，也是线性空间公理体系的核心基础。$\blacksquare$

    实验单元（SymPy）。

    from sympy import Matrix

u = Matrix([3, -1, 2])
v = Matrix([-1, 4, 5])

w = u + v          # 向量加法
print("u + v =", w.T)          # 输出: Matrix([[2, 3, 7]])
print("满足交换律:", u + v == v + u)   # True
print("范数验证:", w.norm().evalf())   # 7.874...

    运行上述代码，可直接观察逐分量加法的结果，并通过 .norm() 验证三角不等式，为后续学习内积与正交性奠定直觉基础。
