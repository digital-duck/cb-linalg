内积

定义。 设 $V$ 是域 $\mathbb{F}$（取 $\mathbb{R}$ 或 $\mathbb{C}$）上的向量空间。内积是一个映射 $\langle \cdot, \cdot \rangle : V \times V \to \mathbb{F}$，满足以下三条公理：

  • 共轭对称性：$\langle \mathbf{u}, \mathbf{v} \rangle = \overline{\langle \mathbf{v}, \mathbf{u} \rangle}$（实数域下即 $\langle \mathbf{u}, \mathbf{v} \rangle = \langle \mathbf{v}, \mathbf{u} \rangle$）；
  • 第一分量线性性：$\langle a\mathbf{u} + b\mathbf{w}, \mathbf{v} \rangle = a\langle \mathbf{u}, \mathbf{v} \rangle + b\langle \mathbf{w}, \mathbf{v} \rangle$，其中 $a, b \in \mathbb{F}$；
  • 正定性：$\langle \mathbf{v}, \mathbf{v} \rangle \geq 0$，且等号成立当且仅当 $\mathbf{v} = \mathbf{0}$。

    • 装备了内积的向量空间称为内积空间。内积自然诱导出范数 $\|\mathbf{v}\| = \sqrt{\langle \mathbf{v}, \mathbf{v} \rangle}$，从而赋予空间度量结构。

    例题。 在 $\mathbb{R}^3$ 中，取 $\mathbf{u} = (1, 2, -1)^{\top}$，$\mathbf{v} = (3, 0, 4)^{\top}$，标准内积定义为

    $$\langle \mathbf{u}, \mathbf{v} \rangle = \mathbf{u}^{\top}\mathbf{v} = \sum_{i=1}^{3} u_i v_i.$$

    计算得

    $$\langle \mathbf{u}, \mathbf{v} \rangle = (1)(3) + (2)(0) + (-1)(4) = 3 + 0 - 4 = -1.$$

    由此可求两向量夹角：$\cos\theta = \dfrac{\langle \mathbf{u}, \mathbf{v} \rangle}{\|\mathbf{u}\|\,\|\mathbf{v}\|}$。其中 $\|\mathbf{u}\| = \sqrt{6}$，$\|\mathbf{v}\| = 5$，故 $\cos\theta = -\dfrac{1}{5\sqrt{6}}$，表明两向量呈钝角。

    关键定理（Cauchy–Schwarz 不等式）。 设 $V$ 为内积空间，对任意 $\mathbf{u}, \mathbf{v} \in V$，有

    $$|\langle \mathbf{u}, \mathbf{v} \rangle|^2 \leq \langle \mathbf{u}, \mathbf{u} \rangle \cdot \langle \mathbf{v}, \mathbf{v} \rangle.$$

    等号成立当且仅当 $\mathbf{u}$ 与 $\mathbf{v}$ 线性相关。证明思路：对任意 $t \in \mathbb{R}$，令 $f(t) = \langle \mathbf{u} - t\mathbf{v},\, \mathbf{u} - t\mathbf{v} \rangle \geq 0$，展开得关于 $t$ 的二次多项式，其判别式非正即得结论。

    实验单元（SymPy）。

    from sympy import Matrix, sqrt, acos, pi, simplify

u = Matrix([1, 2, -1])
v = Matrix([3, 0,  4])

inner = u.dot(v)                          # 内积
norm_u = sqrt(u.dot(u))
norm_v = sqrt(v.dot(v))
angle  = acos(inner / (norm_u * norm_v))

print("内积:", inner)                     # -1
print("‖u‖:", norm_u)                     # sqrt(6)
print("夹角 (rad):", simplify(angle))

    运行后可验证上述手算结果，并进一步修改向量以探索正交条件 $\langle \mathbf{u}, \mathbf{v} \rangle = 0$。
