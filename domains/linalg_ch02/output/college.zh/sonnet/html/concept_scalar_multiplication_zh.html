标量乘法

定义。 设 $\mathbb{F}$ 为一个数域（如 $\mathbb{R}$ 或 $\mathbb{C}$），$V$ 为其上的向量空间。标量乘法是一个映射

$$ \cdot : \mathbb{F} \times V \to V, \quad (c, \mathbf{v}) \mapsto c\mathbf{v}, $$

满足以下公理：对任意 $c, d \in \mathbb{F}$，$\mathbf{u}, \mathbf{v} \in V$，有

  • $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$（对向量加法的分配律）；
  • $(c + d)\mathbf{v} = c\mathbf{v} + d\mathbf{v}$（对标量加法的分配律）；
  • $(cd)\mathbf{v} = c(d\mathbf{v})$（相容性）；
  • $1\mathbf{v} = \mathbf{v}$（单位元性质）。

    • 直观上，标量乘法的作用是缩放：当 $c > 1$ 时，向量被拉长；当 $0 < c < 1$ 时，向量被压短；当 $c < 0$ 时，方向发生反转。

    具体例子。 取 $\mathbb{R}^3$ 中的向量 $\mathbf{v} = (2,\,-1,\,3)^{\top}$，以及标量 $c = -\tfrac{1}{2}$。则

    $$ c\mathbf{v} = -\frac{1}{2}\begin{pmatrix}2\\-1\\3\end{pmatrix} = \begin{pmatrix}-1\\\tfrac{1}{2}\\-\tfrac{3}{2}\end{pmatrix}. $$

    结果向量的模长为原向量的一半，且方向相反：$\|c\mathbf{v}\| = \tfrac{1}{2}\|\mathbf{v}\|$，其中 $\|\mathbf{v}\| = \sqrt{4+1+9} = \sqrt{14}$。

    关键定理（零元与负元）。 设 $V$ 为数域 $\mathbb{F}$ 上的向量空间，$\mathbf{v} \in V$。则：

  • $0\mathbf{v} = \mathbf{0}$；
  • $(-1)\mathbf{v} = -\mathbf{v}$；
  • $c\mathbf{0} = \mathbf{0}$，对一切 $c \in \mathbb{F}$。

    • 证明概述（以第一条为例）： 利用分配律，$0\mathbf{v} = (0+0)\mathbf{v} = 0\mathbf{v} + 0\mathbf{v}$，两边同减 $0\mathbf{v}$，即得 $0\mathbf{v} = \mathbf{0}$。$\blacksquare$

    实验单元（SymPy）。

    from sympy import Matrix, Rational

v = Matrix([2, -1, 3])
c = Rational(-1, 2)

scaled = c * v
print("缩放结果：", scaled.T)
print("原向量模长：", v.norm())
print("缩放后模长：", scaled.norm())

    运行后可验证：scaled.norm() 恰好等于 v.norm() / 2，与理论预测完全一致。读者不妨将 $c$ 替换为其他值（如 $c = 3$ 或 $c = -2$），观察模长与方向的变化规律，以加深对标量乘法几何意义的理解。
