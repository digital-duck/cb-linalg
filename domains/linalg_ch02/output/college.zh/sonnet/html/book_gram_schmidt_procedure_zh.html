格拉姆–施密特正交化：线性代数的自然终点

在本书前几章，我们依次建立了向量空间、线性无关、基与维数、内积空间等概念。每一步都在追问同一个问题：给定一组向量，我们能否找到一种"最干净"的描述方式？格拉姆–施密特正交化过程（Gram–Schmidt Procedure）正是对这个问题的终极回答。

核心定义

设 $V$ 为一个内积空间，$\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}$ 为 $V$ 的一组线性无关向量。格拉姆–施密特过程递推地构造正交规范基 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\}$：

$$ \mathbf{u}_k = \mathbf{v}_k - \sum_{j=1}^{k-1} \frac{\langle \mathbf{v}_k, \mathbf{u}_j \rangle}{\langle \mathbf{u}_j, \mathbf{u}_j \rangle}\,\mathbf{u}_j, \qquad \mathbf{e}_k = \frac{\mathbf{u}_k}{\|\mathbf{u}_k\|} $$

直觉上，每一步将新向量 $\mathbf{v}_k$ 中平行于已有方向的分量全部"剔除"，保留纯粹垂直的余量，再归一化。

具体例题

设 $\mathbf{v}_1 = (1, 1, 0)^\top$，$\mathbf{v}_2 = (1, 0, 1)^\top$，$\mathbf{v}_3 = (0, 1, 1)^\top$，赋以标准内积。

  • $\mathbf{u}_1 = \mathbf{v}_1$，$\mathbf{e}_1 = \frac{1}{\sqrt{2}}(1,1,0)^\top$。
  • $\mathbf{u}_2 = \mathbf{v}_2 - \frac{\langle \mathbf{v}_2,\mathbf{u}_1\rangle}{\|\mathbf{u}_1\|^2}\mathbf{u}_1 = (1,0,1)^\top - \frac{1}{2}(1,1,0)^\top = \tfrac{1}{2}(1,-1,2)^\top$，$\mathbf{e}_2 = \frac{1}{\sqrt{6}}(1,-1,2)^\top$。
  • $\mathbf{u}_3$ 类推，最终得到三个两两正交的单位向量，张成原始子空间。

    • 核心定理

    > 定理（QR分解唯一性） 设 $A$ 为列满秩矩阵，则格拉姆–施密特过程等价于将 $A$ 唯一分解为 $A = QR$，其中 $Q$ 的列为正交规范基，$R$ 为上三角矩阵且对角元均为正。

    正交化的根本价值在于：正交基使投影、距离和最小二乘的计算在数值上稳定、在代数上透明——这是任何依赖内积结构的计算的基础。

    实验室（SymPy）

    from sympy import Matrix, GramSchmidt
vecs = [Matrix([1,1,0]), Matrix([1,0,1]), Matrix([0,1,1])]
orth = GramSchmidt(vecs, orthonormal=True)
for i, e in enumerate(orth):
    print(f"e_{i+1} =", e.T)

    展望

    格拉姆–施密特过程在三个方向上开枝散叶：在数值线性代数中，它是QR算法（特征值计算的工业标准）的心脏；在统计学中，它使最小二乘回归的几何解释一目了然；在信号处理与机器学习中，它是主成分分析（PCA）和正交多项式展开（Legendre、Chebyshev基）的幕后引擎。

    三条路，各有深度。若你对数据压缩与降维充满好奇，不妨以格拉姆–施密特为起点，深入探索主成分分析的世界——你将在那里发现，正交化不只是一种计算技巧，而是理解"信息的本质"的语言。
