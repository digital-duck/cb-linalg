线性无关

定义． 设 $V$ 为域 $\mathbb{F}$ 上的向量空间，$\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\} \subset V$ 为一组向量。若方程

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_n\mathbf{v}_n = \mathbf{0}$$

的唯一解为 $c_1 = c_2 = \cdots = c_n = 0$，则称该向量组线性无关（linearly independent）。若存在不全为零的系数使上式成立，则称该向量组线性相关（linearly dependent）。

直观而言，线性无关意味着组中任一向量均不能由其余向量的线性组合表示——每个向量均为整体贡献了"独立的方向"。

例题． 判断 $\mathbb{R}^3$ 中向量 $\mathbf{v}_1 = (1,0,0)^\top$、$\mathbf{v}_2 = (0,1,2)^\top$、$\mathbf{v}_3 = (0,0,1)^\top$ 是否线性无关。

设 $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + c_3\mathbf{v}_3 = \mathbf{0}$，展开得

$$\begin{pmatrix}c_1\\c_2\\2c_2+c_3\end{pmatrix} = \begin{pmatrix}0\\0\\0\end{pmatrix}.$$

由第一行得 $c_1=0$，由第二行得 $c_2=0$，代入第三行得 $c_3=0$。三系数全为零，故该向量组线性无关。

关键定理（行列式判别法）． 设 $A = [\mathbf{v}_1 \mid \mathbf{v}_2 \mid \cdots \mid \mathbf{v}_n] \in \mathbb{F}^{n\times n}$。则向量组 $\{\mathbf{v}_1,\ldots,\mathbf{v}_n\}$ 线性无关，当且仅当 $\det(A) \neq 0$。

证明梗概． 齐次方程组 $A\mathbf{c} = \mathbf{0}$ 仅有零解，当且仅当 $A$ 可逆，而 $A$ 可逆当且仅当 $\det(A)\neq 0$。$\blacksquare$

实验单元（SymPy）．

from sympy import Matrix

A = Matrix([[1, 0, 0],
            [0, 1, 0],
            [0, 2, 1]])

print("行列式:", A.det())          # 非零 ⟹ 线性无关
print("零空间:", A.nullspace())    # 空列表 ⟹ 仅有零解

运行后若 det 非零且 nullspace() 返回空列表，则判定线性无关。读者可将第三列替换为 $(0,1,2)^\top$ 后重新运行，观察行列式变为零，从而体会线性相关的情形。
