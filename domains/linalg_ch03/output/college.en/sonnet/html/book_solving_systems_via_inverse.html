Payoff

What the Inverse Achieves

Throughout this book we have built, piece by piece, the machinery of linear algebra: vectors, matrices, determinants, and the notion of invertibility. The concept of solving a linear system via the matrix inverse brings this machinery to a single, satisfying conclusion. Given a square system $A\mathbf{x} = \mathbf{b}$ with $A$ invertible, the unique solution is

$$\mathbf{x} = A^{-1}\mathbf{b}.$$

This is not merely a computational shortcut. It is a statement about structure: the map $\mathbf{b} \mapsto A^{-1}\mathbf{b}$ is itself linear, continuous, and exact. Once $A^{-1}$ is known, every right-hand side $\mathbf{b}$ yields its solution in a single matrix–vector multiply — $O(n^2)$ work rather than the $O(n^3)$ cost of re-running Gaussian elimination from scratch. For systems that must be solved repeatedly under varying data (a hallmark of real applications), this amortization is decisive.

Worked Example

Consider the $2 \times 2$ system encoding a simple supply–demand equilibrium:

$$\begin{pmatrix} 3 & -1 \\ -2 & 4 \end{pmatrix} \begin{pmatrix} p \\ q \end{pmatrix} = \begin{pmatrix} 5 \\ 8 \end{pmatrix}.$$

The coefficient matrix has determinant $3(4) - (-1)(-2) = 10 \neq 0$, so the inverse exists:

$$A^{-1} = \frac{1}{10}\begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}.$$

Applying it directly:

$$\begin{pmatrix} p \\ q \end{pmatrix} = \frac{1}{10}\begin{pmatrix} 4(5)+1(8) \\ 2(5)+3(8) \end{pmatrix} = \frac{1}{10}\begin{pmatrix} 28 \\ 34 \end{pmatrix} = \begin{pmatrix} 2.8 \\ 3.4 \end{pmatrix}.$$

No row operations; no back-substitution. One multiplication.

Key Theorem

Invertibility Criterion. A square matrix $A \in \mathbb{R}^{n \times n}$ is invertible if and only if $\det(A) \neq 0$, equivalently, if and only if $A\mathbf{x} = \mathbf{b}$ has a unique solution for every $\mathbf{b}$. When these conditions hold, $A^{-1}$ exists, is unique, and satisfies $AA^{-1} = A^{-1}A = I$.

Proof sketch. If $\det(A) \neq 0$, Gaussian elimination produces $n$ nonzero pivots, yielding a unique reduced form and hence a unique $\mathbf{x}$. The explicit formula $A^{-1} = \frac{1}{\det(A)}\operatorname{adj}(A)$ then follows from the cofactor expansion. $\square$

Lab Cell (SymPy)

from sympy import Matrix, symbols, pprint

A = Matrix([[3, -1], [-2, 4]])
b = Matrix([5, 8])

A_inv = A.inv()
pprint(A_inv)          # inspect the inverse symbolically

x = A_inv * b
pprint(x)              # solution vector

Run this cell and then substitute a second right-hand side, say $\mathbf{b}' = (1, 0)^\top$, to observe that only the multiply changes — $A^{-1}$ is computed once and reused.
