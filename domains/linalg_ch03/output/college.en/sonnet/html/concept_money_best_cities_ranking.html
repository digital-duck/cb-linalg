Money Best Cities Ranking

Definition

A money best-cities ranking is a composite linear scoring procedure that reduces a high-dimensional municipal attribute vector to a single real-valued index, enabling a total ordering of cities by economic desirability. Formally, let $\mathcal{C} = \{c_1, c_2, \ldots, c_n\}$ be a finite set of cities and let each city $c_i$ be described by an attribute matrix $\mathbf{x}_i \in \mathbb{R}^m$, where the $j$-th component $x_{ij}$ records the raw value of indicator $j$ (e.g., median household income, cost of living index, unemployment rate). Because indicators carry incommensurable units, each column is first min–max normalized:

$$\tilde{x}_{ij} = \frac{x_{ij} - \min_k x_{kj}}{\max_k x_{kj} - \min_k x_{kj}} \in [0,1].$$

A weight vector $\mathbf{w} \in \mathbb{R}^m$ with $\mathbf{w} \geq \mathbf{0}$ and $\|\mathbf{w}\|_1 = 1$ encodes editorial priorities. The composite score of city $c_i$ is then

$$S_i = \sum_{j=1}^{m} w_j \tilde{x}_{ij} = \mathbf{w}^\top \tilde{\mathbf{x}}_i.$$

Cities are ranked by $S_i$ in descending order; rank $r_i = 1$ denotes the most desirable city.

Worked Example

Consider three cities—Austin, Denver, and Raleigh—evaluated on two indicators: normalized income ($j=1$) and inverted cost-of-living ($j=2$, so higher is cheaper). Suppose

$$\tilde{X} = \begin{pmatrix} 0.8 & 0.5 \\ 0.6 & 0.9 \\ 0.7 & 0.7 \end{pmatrix}, \quad \mathbf{w} = \begin{pmatrix} 0.6 \\ 0.4 \end{pmatrix}.$$

Then $S_{\text{Austin}} = 0.6(0.8)+0.4(0.5) = 0.68$, $S_{\text{Denver}} = 0.6(0.6)+0.4(0.9) = 0.72$, $S_{\text{Raleigh}} = 0.6(0.7)+0.4(0.7) = 0.70$. The ranking is Denver $\succ$ Raleigh $\succ$ Austin.

Key Theorem (Rank Sensitivity)

Theorem. The ranking $r_i < r_k$ is reversed by a perturbation $\Delta \mathbf{w}$ satisfying $\mathbf{1}^\top \Delta\mathbf{w} = 0$ if and only if $(\tilde{\mathbf{x}}_i - \tilde{\mathbf{x}}_k)^\top \Delta\mathbf{w} < 0$.

Proof sketch. The score gap $S_i - S_k = \mathbf{w}^\top(\tilde{\mathbf{x}}_i - \tilde{\mathbf{x}}_k)$ changes sign exactly when the inner product with the difference vector $\delta = \tilde{\mathbf{x}}_i - \tilde{\mathbf{x}}_k$ changes sign under $\mathbf{w} + \Delta\mathbf{w}$, giving the stated linear condition. $\square$

This theorem quantifies editorial instability: cities with nearly equal scores on all indicators are robust to weight changes, while cities that excel on only a subset are sensitive.

Lab Cell

import sympy as sp

# Attribute matrix (rows = cities, cols = indicators)
X_raw = sp.Matrix([[80000, 95], [70000, 75], [75000, 85]])
cities = ["Austin", "Denver", "Raleigh"]

# Min-max normalization (column-wise)
X_norm = sp.zeros(*X_raw.shape)
for j in range(X_raw.cols):
    col = X_raw.col(j)
    lo, hi = min(col), max(col)
    for i in range(X_raw.rows):
        X_norm[i, j] = (col[i] - lo) / (hi - lo)

w = sp.Matrix([sp.Rational(3, 5), sp.Rational(2, 5)])
scores = X_norm * w
ranking = sorted(zip(cities, scores), key=lambda t: -t[1])
for rank, (city, score) in enumerate(ranking, 1):
    print(f"{rank}. {city}: {float(score):.4f}")
