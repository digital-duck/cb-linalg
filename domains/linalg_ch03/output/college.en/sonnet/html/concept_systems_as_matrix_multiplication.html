Systems As Matrix Multiplication

Definition. A system of linear equations in $n$ unknowns $x_1, x_2, \ldots, x_n$ is a collection of $m$ equations of the form

$$\sum_{j=1}^{n} a_{ij} x_j = b_i, \qquad i = 1, 2, \ldots, m,$$

where $a_{ij}, b_i \in \mathbb{R}$. This system admits a compact encoding as a single matrix equation. Define the coefficient matrix $A = (a_{ij}) \in \mathbb{R}^{m \times n}$, the unknown vector $\mathbf{x} = (x_1, \ldots, x_n)^\top \in \mathbb{R}^n$, and the right-hand side vector $\mathbf{b} = (b_1, \ldots, b_m)^\top \in \mathbb{R}^m$. The entire system is then equivalent to the matrix equation

$$A\mathbf{x} = \mathbf{b}.$$

The product $A\mathbf{x}$ is computed as $\sum_{j=1}^{n} a_{ij} x_j$ for each row $i$, which recovers each scalar equation precisely.

Worked Example. Consider the system

$$2x_1 + 3x_2 = 8, \qquad x_1 - x_2 = 1.$$

We identify

$$A = \begin{pmatrix} 2 & 3 \\ 1 & -1 \end{pmatrix}, \quad \mathbf{x} = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}, \quad \mathbf{b} = \begin{pmatrix} 8 \\ 1 \end{pmatrix}.$$

Verifying with the solution $x_1 = \tfrac{11}{5}$, $x_2 = \tfrac{6}{5}$:

$$A\mathbf{x} = \begin{pmatrix} 2 \cdot \frac{11}{5} + 3 \cdot \frac{6}{5} \\ 1 \cdot \frac{11}{5} - 1 \cdot \frac{6}{5} \end{pmatrix} = \begin{pmatrix} \frac{40}{5} \\ \frac{5}{5} \end{pmatrix} = \begin{pmatrix} 8 \\ 1 \end{pmatrix} = \mathbf{b}. \checkmark$$

Key Theorem (Existence and Uniqueness). The system $A\mathbf{x} = \mathbf{b}$ has a unique solution if and only if $A$ is square and $\det(A) \neq 0$, in which case $\mathbf{x} = A^{-1}\mathbf{b}$. When $A$ is not square or is singular, solutions may be non-unique or absent; the full characterization relies on the rank-nullity theorem: the solution set is non-empty if and only if $\mathbf{b} \in \mathrm{col}(A)$, and the general solution is $\mathbf{x}_p + \ker(A)$ for any particular solution $\mathbf{x}_p$.

Lab Cell.

from sympy import Matrix, symbols, linsolve

x1, x2 = symbols('x1 x2')
A = Matrix([[2, 3], [1, -1]])
b = Matrix([8, 1])

# Solve via matrix inverse
sol_vec = A.inv() * b
print("Solution vector:", sol_vec)

# Verify residual
print("Residual A x - b:", A * sol_vec - b)

# Alternatively, use linsolve
sol_set = linsolve((A, b), x1, x2)
print("linsolve result:", sol_set)

Running this cell confirms $x_1 = \tfrac{11}{5}$ and $x_2 = \tfrac{6}{5}$, with a zero residual, validating the matrix-multiplication encoding of the original system.
