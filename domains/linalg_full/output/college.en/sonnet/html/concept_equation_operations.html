Equation Operations

Definition. An equation is a formal assertion of equality between two mathematical expressions, written $L = R$, where $L$ and $R$ denote the left-hand side and right-hand side, respectively. An equation operation is any transformation applied simultaneously to both sides of an equation that preserves the truth of the equality. Formally, if $L = R$ holds in a given domain, and $f$ is a function defined on that domain, then $f(L) = f(R)$ holds as well. The elementary equation operations are: addition of a constant ($L + c = R + c$), subtraction ($L - c = R - c$), multiplication by a nonzero scalar ($cL = cR$, $c \neq 0$), division by a nonzero scalar, and the application of any injective function on an appropriate domain (e.g., squaring is not injective on $\mathbb{R}$, and can introduce extraneous solutions).

Worked Example. Solve the linear equation $3x - 7 = 11$.

  • Add $7$ to both sides: $3x - 7 + 7 = 11 + 7$, giving $3x = 18$.
  • Divide both sides by $3$: $\dfrac{3x}{3} = \dfrac{18}{3}$, giving $x = 6$.
  • Verify by substitution: $3(6) - 7 = 18 - 7 = 11$. $\checkmark$

    • Each step applies a valid equation operation, so the solution set is preserved at every stage.

    Key Theorem (Equivalence Preservation). Let $S$ denote the solution set of $L = R$ over a domain $D$. If $f : D \to D'$ is injective, then the equation $f(L) = f(R)$ has the same solution set $S$. If $f$ is not injective, the new solution set $S'$ may satisfy $S \subseteq S'$, meaning extraneous solutions can appear and all candidates must be checked against the original equation.

    Proof sketch. Injectivity means $f(a) = f(b) \Rightarrow a = b$. Thus every solution of $f(L) = f(R)$ is also a solution of $L = R$, establishing $S' \subseteq S$ and $S \subseteq S'$, hence $S = S'$. Without injectivity, the reverse implication fails, permitting $S' \supsetneq S$.

    Lab Cell.

    from sympy import symbols, Eq, solve

x = symbols('x')
eq = Eq(3*x - 7, 11)

# Apply equation operations manually
eq_step1 = Eq(eq.lhs + 7, eq.rhs + 7)   # add 7 to both sides
eq_step2 = Eq(eq_step1.lhs / 3, eq_step1.rhs / 3)  # divide by 3

print("After step 1:", eq_step1)
print("After step 2:", eq_step2)
print("Solution via solve():", solve(eq, x))

    Running this cell prints x = 6, confirming that the manual sequence of equation operations agrees with SymPy's internal solver.
