Determinant Row Column Multiple

Definition. Let $A$ be an $n \times n$ matrix and let $B$ be the matrix obtained from $A$ by multiplying a single row (or a single column) by a scalar $k \in \mathbb{R}$. Then

$$\det(B) = k \cdot \det(A).$$

More precisely, if $B$ differs from $A$ only in row $i$, with $B_{i,\cdot} = k\, A_{i,\cdot}$ and all other rows unchanged, then $\det(B) = k\,\det(A)$. The same holds when a single column is scaled.

This property follows directly from the multilinearity of the determinant: $\det$ is linear in each row (and in each column) separately. Factoring the scalar $k$ out of the $i$-th row in the Leibniz expansion immediately yields the result.

Worked Example. Consider

$$A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}, \qquad \det(A) = (1)(4) - (2)(3) = -2.$$

Scale row 1 by $k = 5$:

$$B = \begin{pmatrix} 5 & 10 \\ 3 & 4 \end{pmatrix}.$$

Computing directly, $\det(B) = (5)(4) - (10)(3) = 20 - 30 = -10$. Indeed, $-10 = 5 \cdot (-2)$, confirming the rule.

Note carefully: scaling every row by $k$ multiplies the determinant by $k^n$, not $k$. This is a frequent source of error — only one row (or column) is scaled in the theorem above.

Key Theorem (Row/Column Scaling). For any $n \times n$ matrix $A$ and scalar $k$,

$$\det(\text{Scale}_i(k,A)) = k\,\det(A),$$

where $\text{Scale}_i(k,A)$ denotes scaling row $i$ by $k$. As a corollary, if $k = 0$ then $\det(B) = 0$, reflecting the fact that a zero row renders the matrix singular. Furthermore, $\det(kA) = k^n \det(A)$, since all $n$ rows are simultaneously scaled.

Lab Cell (SymPy).

from sympy import Matrix, symbols

k = symbols('k')
A = Matrix([[1, 2], [3, 4]])
B = A.copy()
B.row_op(0, lambda v, _: k * v)   # scale row 0 by k

print("det(A) =", A.det())        # -2
print("det(B) =", B.det())        # -2k
print("k * det(A) =", k * A.det()) # -2k

Running this cell produces det(B) = -2k and k * det(A) = -2k, verifying the theorem symbolically for arbitrary $k$.
