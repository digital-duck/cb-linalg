Determinant Definition

Definition. Let $A = [a_{ij}]$ be an $n \times n$ matrix over a field $\mathbb{F}$ (typically $\mathbb{R}$ or $\mathbb{C}$). The determinant of $A$, denoted $\det(A)$ or $|A|$, is the scalar defined recursively by

$$\det(A) = \sum_{j=1}^{n} (-1)^{1+j}\, a_{1j}\, \det(A_{1j}),$$

where $A_{1j}$ is the $(n-1)\times(n-1)$ minor obtained by deleting row $1$ and column $j$ from $A$. The base case is $\det([a]) = a$ for a $1 \times 1$ matrix. This expansion along the first row is called cofactor expansion; it yields the same value when expanded along any row or column.

Geometrically, $|\det(A)|$ measures the factor by which $A$ scales $n$-dimensional volume, and $\text{sgn}(\det(A))$ records whether the linear map preserves or reverses orientation.

Worked Example. Compute $\det(A)$ for

$$A = \begin{pmatrix} 2 & 1 & 3 \\ 0 & -1 & 4 \\ 5 & 2 & 1 \end{pmatrix}.$$

Expanding along row 1:

$$\det(A) = 2\,\det\!\begin{pmatrix}-1&4\\2&1\end{pmatrix} - 1\,\det\!\begin{pmatrix}0&4\\5&1\end{pmatrix} + 3\,\det\!\begin{pmatrix}0&-1\\5&2\end{pmatrix}.$$

Evaluating each $2\times 2$ determinant via $\det\!\begin{pmatrix}a&b\\c&d\end{pmatrix} = ad - bc$:

$$= 2[(-1)(1)-(4)(2)] - 1[(0)(1)-(4)(5)] + 3[(0)(2)-(-1)(5)]$$ $$= 2(-9) - 1(-20) + 3(5) = -18 + 20 + 15 = 17.$$

Key Theorem (Invertibility Criterion). An $n\times n$ matrix $A$ is invertible if and only if $\det(A)\neq 0$.

Proof sketch. Row reduction transforms $A$ into its reduced row echelon form. Each elementary row operation multiplies the determinant by a nonzero scalar (row swap changes sign; row scaling multiplies by the scalar; row addition leaves it unchanged). Hence $\det(A) = 0$ if and only if some row reduces to zero, which occurs precisely when the columns are linearly dependent—equivalently, when $A$ has no inverse. $\square$

Lab Cell (SymPy).

from sympy import Matrix, det, symbols

A = Matrix([[2, 1, 3],
            [0, -1, 4],
            [5,  2, 1]])

print("det(A) =", det(A))          # Expected: 17

x = symbols('x')
B = Matrix([[x, 1], [1, x]])
print("det(B) =", det(B))          # Expected: x**2 - 1
